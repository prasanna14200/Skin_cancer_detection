# Nine-class dataset protocol decision — Stage 3 completion

Status: **recommendation for approval, not a frozen manifest or split** (2026-10-19). See [pipeline evidence](NINE_CLASS_DATA_PIPELINE.md) and `analysis/nine_class_overlap_completion/completion_summary.json` for reproducible counts.

## What the paper establishes

The [EG-VAN paper (DOI 10.1109/ACCESS.2025.3561240)](https://www.researchgate.net/publication/390831641_EG-VAN_A_Global_and_Local_Attention_based_Dual-Branch_Ensemble_Network_with_Advanced_color_balancing_for_Multi-Class_Skin_Cancer_Recognition), §III–IV, describes seven HAM10000 diagnoses (10,015 images) plus 3,297 benign/malignant entries as nine source-defined output categories. It reports morphological hair removal and inpainting, Gray World correction, Retinex, cropping/resizing, and 20 augmentation transformations; 25 epochs, batch size 32, Adamax with initial learning rate 0.001, and focal loss; and 98.20% nine-class accuracy. It reports a HAM test set of 1,332 original images and augmented train/validation counts of 37,883/6,686. Its exact source package/version, per-image assignments, binary source-test treatment, numeric class encoding, crop size, preprocessing numerical parameters, augmentation definitions and timing for every source, split seed, grouping, and duplicate policy are not fully recoverable. The reported accuracy is a paper result, not a valid local target for selecting samples or splits.

The local HAM image count agrees, and the local canonical binary tree `data/isic/data/` contains 3,297 entries with matching broad label counts. **Matching counts do not verify source identity or reproduce the paper's image assignments.** Binary folder labels are available but clinical label derivation, patient/lesion IDs, version, and license remain unverified. The mirrored `data/isic/{train,test}/` tree is excluded from all proposed sampling.

## Protocol comparison

| Question | A: paper-reported reconstruction | B: leakage-controlled reconstruction |
| --- | --- | --- |
| Task and model | Paper's nine source-defined labels and EG-VAN global/local dual-branch design | Same intended nine source-defined labels and architecture; no relabeling HAM diagnoses |
| Paper methodology | Use reported color-balancing sequence, augmentation concept, 25 epochs, batch 32, Adamax 0.001, focal loss, and paper evaluation description | Preserve verified methods/settings where feasible; mark local numerical preprocessing, augmentations, image sizing, and split implementation as adaptations |
| Data identity | Local 3,297 count is consistent, exact package/version and image assignments unverified | Canonical local HAM plus `data/isic/data/`, with explicit source and version uncertainty |
| Overlap | Paper does not document how thousands of recompressed same photographs or binary source train/test conflicts were handled | Exclude confirmed HAM photo copies from binary sampling; group all confirmed relations and genuine HAM lesion IDs; quarantine unresolved high-risk relations before split |
| Test boundary | Original 1,332-image HAM test membership and binary source-test handling unavailable | Never use binary source-test images for training; determine whether this local source split is official before freezing; group source train/test conflicts and hold unresolved ones |
| Reproducibility | **Exact reproduction infeasible** from current evidence | Conditional, documented research adaptation, subject to human review and source/protocol approval |

The nine targets mix seven diagnostic subtypes with two broader outcomes. A melanoma may also be malignant and a nevus benign, so a nine-way softmax is a **source-conditioned label task**, not nine mutually exclusive clinical diagnoses. Source-specific resolution and processing can also become shortcuts. Neither protocol can claim patient-independent evaluation because the binary collection lacks verified patient identifiers. Report nine-class macro and per-class metrics, source-specific metrics, confusion matrices, and confidence intervals where sample sizes permit; avoid interpreting overall accuracy alone as clinical validity.

## Recommendation and gate

**Recommend Protocol B only as a conditional paper-aligned adaptation. Do not freeze a manifest or split yet.** The current benign pool is very small and every retained benign entry needs review; the 19 proposed benign source-test entries make nine-class evaluation fragile. The project should accept the source-conditioned target and provenance limitations explicitly, then adjudicate the focused queue (starting with all retained benign candidates and source-test conflicts). Each human decision should record both source-qualified paths, evidence, reviewer, date, and whether it establishes same photograph, possible same lesion, distinct, or unresolved. Unconfirmed visual similarity must not be automatically excluded. Recompute transitive groups and class counts after decisions; stop if the remaining benign/test set cannot support a meaningful evaluation.

After that gate, generate a combined source-qualified manifest and exclusion ledger, preserve the protected binary test boundary, group verified HAM lesion IDs plus confirmed photo/lesion relations, and build a deterministic class-stratified split where feasible. Freeze a seed and achieved counts, check no relation crosses partitions, and keep final test untouched. A local 80/10/10 seed-42 target remains an **adaptation proposal**, not a paper-reported rule. Apply deterministic validation/test preprocessing and training-only random augmentation. Approval for this recommendation is separate from authorization to create those later artifacts.
